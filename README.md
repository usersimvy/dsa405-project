# Wake County Food Safety Inspections — DSA 405 Project (Milestone 2)

## 1. Project Overview
This project performs an end-to-end data audit, cleaning pipeline, and accounting reconciliation on commercial food safety inspection data from Wake County, North Carolina.

## 2. Data Origin & Provenance
* **Source:** Wake County Environmental Services Department
* **Dataset:** `Food_Inspections.csv`
* **Raw File Path:** `data/raw/Food_Inspections.csv`

## 3. How to Run
1. Open the notebook in Google Colab using the badge link in the notebook file.
2. Select **Runtime -> Restart session and run all** to execute the pipeline from top to bottom.
